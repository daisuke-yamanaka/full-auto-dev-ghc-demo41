## 2. デザイン仕様（パターンB）

### 2.1 ナビゲーション構造
- SCR002 と同じドロワーメニュー構造
- ページ上部に「← 戻る」リンク（前の画面へ）

### 2.2 カラー仕様
SCR002 と同様（主要カラー: プライマリ #1a73e8 / アクセント #00897b / 背景 #f8f9fa / カード背景 #ffffff / テキスト #202124）

### 2.3 コンポーネントスタイル

**図書情報カード**:
- 図書タイトル（h2）、著者名、ISBN、出版社、出版年、カテゴリを表示
- 在庫状況: 「貸出可能 N冊」または「全冊貸出中（返却予定: YYYY/MM/DD）」バッジ
- 予約件数表示（例: 「予約 2件」）
- **自分の予約順位表示**（`currentUserStatus=reserved` の場合のみ）: 「あなたは N番目に予約しています」（プライマリカラーでハイライト）

**操作ボタンエリア**:
- 貸出ボタン: プライマリカラー（#1a73e8）、幅広ボタン
- 予約ボタン: アクセントカラー（#00897b）
- 返却ボタン: アクセントカラー（#00897b）、「返却する」テキスト
- 予約キャンセルボタン: アウトラインボタン（ボーダーのみ）
- 編集ボタン（ADMIN）: セカンダリ（グレー）
- 削除ボタン（ADMIN）: 危険色（#d93025）

### 2.4 空状態
- 非適用（書籍情報は常時表示）

### 2.5 ローディング状態
- スケルトン表示

### 2.6 エラー状態
- 図書が存在しない（404）: 「図書が見つかりませんでした」と一覧に戻るリンク

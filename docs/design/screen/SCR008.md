## 2. デザイン仕様（パターンB）

### 2.1 ナビゲーション構造
- SCR002 と同じドロワーメニュー構造
- アクティブメニュー: 「予約一覧」をハイライト

### 2.2 カラー仕様
SCR002 と同様（主要カラー: プライマリ #1a73e8 / アクセント #00897b / 背景 #f8f9fa / カード背景 #ffffff / テキスト #202124）

### 2.3 コンポーネントスタイル

**予約一覧カード / テーブル行**:
- PC: テーブル形式（図書名・著者・予約日・予約順位・操作）
- モバイル: カード形式
- 予約順位: 数字バッジで表示（1位=プライマリカラー）
- 図書タイトルはリンク（SCR005 へ）
- キャンセルボタン: アウトライン（ボーダーのみ）

**ページネーション**: プライマリカラーでハイライト

### 2.4 空状態
- 予約0件: 「現在予約中の図書はありません」と「図書を探す」リンクボタンを表示

### 2.5 ローディング状態
- スケルトン表示

### 2.6 エラー状態
- API エラー: エラーメッセージとリロードボタン

### 2.7 確認ダイアログ仕様
- **予約キャンセル確認ダイアログ（モーダル）**:
  - タイトル: 「予約のキャンセル確認」
  - 本文: 「「{図書名}」の予約をキャンセルしますか？」
  - ボタン: 「キャンセルする」（危険色 #d93025）・「閉じる」（グレー）
  - 「閉じる」またはダイアログ外クリックで閉じる（API コールなし）

## 5. アクション定義

| アクションID | 説明 | トリガー | APIエンドポイント | 動作 |
|------------|------|---------|----------------|------|
| A01 | 予約一覧読込 | ページ読込時 | GET /api/me/reservations | 自分の予約一覧を取得して表示する（ページネーション対応） |
| A02 | 予約キャンセル確認ダイアログ表示 | B14（キャンセルボタン）押下 | なし | B17（確認ダイアログ）を表示する |

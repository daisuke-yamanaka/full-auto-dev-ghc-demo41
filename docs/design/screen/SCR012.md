## 2. デザイン仕様（パターンB）

### 2.1 ナビゲーション構造
- SCR002 と同じドロワーメニュー構造
- アクティブメニュー: 「図書管理」をハイライト（ADMINのみ表示）

### 2.2 カラー仕様
SCR002 と同様（主要カラー: プライマリ #1a73e8 / アクセント #00897b / 背景 #f8f9fa / カード背景 #ffffff / テキスト #202124）

### 2.3 コンポーネントスタイル

**図書一覧テーブル**:
- PC: テーブル形式（タイトル・著者・ISBN・カテゴリ・蔵書数・在庫・操作）
- モバイル: カード形式
- 在庫0冊: 赤色でハイライト
- 操作ボタン（各行）: 編集（SCR006 へ遷移）、削除（赤アイコン）

**検索フォーム**:
- 一覧上部にテーブル型検索フォーム（タイトル・著者・カテゴリ・ISBN）
- 検索ボタン: プライマリカラー

**削除確認ダイアログ**:
- 「本当にこの図書を削除しますか？」確認テキスト
- 確認/キャンセルボタン

### 2.4 空状態
- 検索結果0件: 「該当する図書が見つかりませんでした」と検索クリアボタン
- 図書0件（初期）: 「図書が登録されていません」と「図書を追加」ボタン

### 2.5 ローディング状態
- テーブルスケルトンを表示

### 2.6 エラー状態
- API エラー: エラーメッセージとリロードボタン
- **403 Forbidden（権限エラー）**: 非ADMINユーザがこの画面URLに直接アクセスした場合、フロントエンドのルートガードにより403エラーページへリダイレクトする

## 5. アクション定義

| アクションID | 説明 | トリガー | APIエンドポイント | 動作 |
|------------|------|---------|----------------|------|
| A01 | 図書一覧読込 | ページ読込時 | GET /api/books | 検索条件なしで全件（1ページ目）を取得して表示する |
| A02 | 図書検索 | B16（検索ボタン）押下 または Enterキー | GET /api/books | 入力された検索条件をクエリパラメータに付けて検索を実行する |
| A03 | 図書追加画面へ遷移 | B17（図書追加ボタン）押下 | なし（画面遷移） | SCR006（図書フォーム画面・新規モード）へ遷移する |
| A04 | 図書編集画面へ遷移 | B19（編集ボタン）押下 | なし（画面遷移） | SCR006（図書フォーム画面・編集モード）へ遷移する（bookId を URL パラメータで渡す） |
| A05 | 削除確認ダイアログ表示 | B20（削除ボタン）押下 | なし | 対象図書の情報をセットして削除確認ダイアログ（B21）を表示する |
| A06 | 図書削除 | 削除確認ダイアログの確認ボタン押下 | DELETE /api/admin/books/{id} | 対象図書の version をリクエストに含めて削除 API を呼び出す。成功時はダイアログを閉じて一覧再読込。409 時はエラーメッセージ |
| A07 | ページ切り替え | B22（ページネーション）押下 | GET /api/books | 指定ページの図書一覧を取得する |
| A08 | アクティビティフィードへ遷移 | B03 押下 | なし（画面遷移） | SCR002 へ遷移する |
| A09 | ダッシュボードへ遷移 | B04 押下 | なし（画面遷移） | SCR003 へ遷移する |
| A10 | 図書一覧へ遷移 | B05 押下 | なし（画面遷移） | SCR004 へ遷移する |
| A11 | 貸出履歴へ遷移 | B06 押下 | なし（画面遷移） | SCR007 へ遷移する |
| A12 | 予約一覧へ遷移 | B07 押下 | なし（画面遷移） | SCR008 へ遷移する |
| A13 | プロフィールへ遷移 | B10 押下 | なし（画面遷移） | SCR009 へ遷移する |
| A14 | 図書管理へ遷移 | B08 押下 | なし（画面遷移） | SCR012（現在画面）へ遷移する |
| A15 | ユーザ管理へ遷移 | B09 押下 | なし（画面遷移） | SCR011 へ遷移する |
| A16 | ログアウト | B11 押下 | POST /api/auth/logout | ログアウト処理を実行し SCR001 へ遷移する |

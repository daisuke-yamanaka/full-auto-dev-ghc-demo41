## 2. デザイン仕様（パターンB）

### 2.1 ナビゲーション構造
- SCR002 と同じドロワーメニュー構造
- ページ上部に「← 戻る」リンク
- ページタイトル: 新規モード「図書登録」、編集モード「図書編集」

### 2.2 カラー仕様
SCR002 と同様（主要カラー: プライマリ #1a73e8 / アクセント #00897b / 背景 #f8f9fa / カード背景 #ffffff / テキスト #202124）

### 2.3 コンポーネントスタイル

**フォームカード**:
- カード型（background #ffffff、border-radius: 8px、box-shadow）
- 各フィールドにラベルと入力フィールドを縦並びで配置
- 必須フィールドにはラベル横に「*」を赤色で表示
- バリデーションエラー時: フィールド下部に赤色エラーメッセージ表示

**ボタンエリア**:
- 保存ボタン: プライマリカラー（#1a73e8）
- キャンセルボタン: アウトライン（ボーダーのみ）

### 2.4 空状態
- 非適用

### 2.5 ローディング状態
- 編集モード時の初期データ読込中: スケルトン表示
- 保存ボタン押下中: スピナー表示・ボタン非活性

### 2.6 エラー状態
- バリデーションエラー: 各フィールド下にエラーメッセージ表示
- API エラー（ISBN重複等）: フォーム上部にアラート表示
- **403 Forbidden（権限エラー）**: 非ADMINユーザがこの画面URLに直接アクセスした場合、フロントエンドのルートガードにより403エラーページへリダイレクトする

## 5. アクション定義

| アクションID | 説明 | トリガー | APIエンドポイント | 動作 |
|------------|------|---------|----------------|------|
| A00 | 編集対象図書の初期データ取得 | ページ読込時（編集モードのみ） | GET /api/books/{id} | URL パラメータの bookId を使って図書詳細を取得し、各フィールドに初期値としてセットする。取得した version も保持して更新時に使用する |
| A01 | 図書登録 | B20（保存ボタン）押下（新規モード） | POST /api/admin/books | 入力内容を検証後、図書登録 API を呼び出す。成功時は SCR012（図書管理画面）へ遷移し、スナックバー表示 |

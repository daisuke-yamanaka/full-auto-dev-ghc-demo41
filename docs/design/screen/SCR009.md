## 2. デザイン仕様（パターンB）

### 2.1 ナビゲーション構造
- SCR002 と同じドロワーメニュー構造
- ヘッダーのアバターアイコンからアクセスされる

### 2.2 カラー仕様
SCR002 と同様（主要カラー: プライマリ #1a73e8 / アクセント #00897b / 背景 #f8f9fa / カード背景 #ffffff / テキスト #202124）

### 2.3 コンポーネントスタイル

**プロフィールカード**:
- ユーザアバター（イニシャルまたはアイコン）を中央上部に表示
- 名前入力フィールド: 編集可能
- ユーザID・メールアドレス: 読取専用フィールド（グレー背景、編集不可）
- フォントサイズ選択: ラジオボタンまたはセグメントコントロール（標準/大/特大）
- 保存ボタン: プライマリカラー
- パスワード変更リンク: テキストリンク

### 2.4 空状態
- 非適用

### 2.5 ローディング状態
- 初期データ読込中: スケルトン表示

### 2.6 エラー状態
- バリデーションエラー: フィールド下にエラーメッセージ表示
- API エラー（楽観的ロック等）: スナックバーでエラー表示

## 5. アクション定義

| アクションID | 説明 | トリガー | APIエンドポイント | 動作 |
|------------|------|---------|----------------|------|
| A01 | プロフィール読込 | ページ読込時 | GET /api/me/profile | ログイン中ユーザのプロフィール情報（name/userId/email/role/fontSize/version）を取得してフォームに設定する |
| A02 | プロフィール保存 | B16（保存ボタン）押下 | PUT /api/me/profile + PUT /api/me/settings（fontSize変更時のみ） | 名前の変更を PUT /api/me/profile で送信（version含む）。fontSize が変更された場合は PUT /api/me/settings も呼び出す。成功時は「プロフィールを更新しました」スナックバー表示。楽観的ロックエラー（409）時は「他の端末から変更が行われました。再読み込みしてください。」を表示 |
| A03 | パスワード変更画面へ遷移 | B17（パスワード変更リンク）押下 | なし（画面遷移） | SCR010（パスワード変更画面）へ遷移する |

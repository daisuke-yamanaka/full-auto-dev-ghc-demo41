## 2. デザイン仕様（パターンB）

### 2.1 ナビゲーション構造
- SCR002 と同じドロワーメニュー構造
- ページ上部またはフォーム下部に「← プロフィールに戻る」リンク

### 2.2 カラー仕様
SCR002 と同様（主要カラー: プライマリ #1a73e8 / アクセント #00897b / 背景 #f8f9fa / カード背景 #ffffff / テキスト #202124）

### 2.3 コンポーネントスタイル

**パスワード変更フォームカード**:
- カード型（background #ffffff、border-radius: 8px、box-shadow）
- 3つのパスワード入力フィールド（目のアイコンで表示/非表示切替）
- パスワード強度インジケータ: 新しいパスワード入力欄の下に表示
  - 弱（< 8文字）: 赤色のプログレスバー（33%）
  - 普通（8文字以上・英字または数字のみ）: 黄色（66%）
  - 強（8文字以上・英数字混在）: 緑色（100%）
- 変更ボタン: プライマリカラー（#1a73e8）
- キャンセルリンク: テキストリンク

### 2.4 空状態
- 非適用

### 2.5 ローディング状態
- 変更ボタン押下中: スピナー表示・ボタン非活性

### 2.6 エラー状態
- 現在のパスワード不一致: フィールド下にエラーメッセージ
- 新パスワード不一致: フィールド下にエラーメッセージ
- API エラー: フォーム上部にアラート表示

## 4. ボタン表示条件

| ユーザ状態 | B12〜B14 入力フィールド | B15 強度表示 | B16 変更ボタン | B17 キャンセルリンク |
|----------|---------------------|------------|-------------|-------------------|
| 未入力あり（いずれかのフィールドが空） | 表示（活性） | 非表示（B13 未入力時） | 表示（非活性） | 表示（活性） |
| 全項目入力済み・パスワード一致・バリデーションOK | 表示（活性） | 表示（活性） | 表示（活性） | 表示（活性） |
| B13 と B14 が不一致 | 表示（活性）※B14 エラー | 表示（活性） | 表示（非活性） | 表示（活性） |
| B13 が 8 文字未満 | 表示（活性）※B13 エラー | 表示（活性）※弱 | 表示（非活性） | 表示（活性） |
| 変更処理中 | 表示（非活性） | 表示（活性） | 表示（非活性）※スピナー | 表示（非活性） |

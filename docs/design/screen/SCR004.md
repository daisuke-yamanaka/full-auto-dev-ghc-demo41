## 2. デザイン仕様（パターンB）

### 2.1 ナビゲーション構造
- SCR002 と同じドロワーメニュー構造
- アクティブメニュー: 「図書を探す」をハイライト

### 2.2 カラー仕様
SCR002 と同様（主要カラー: プライマリ #1a73e8 / アクセント #00897b / 背景 #f8f9fa / カード背景 #ffffff / テキスト #202124）

### 2.3 コンポーネントスタイル

**検索フォームカード**:
- カード型（background #ffffff、border-radius: 8px、box-shadow）
- タイトル・著者テキスト入力、カテゴリセレクト、ISBN テキスト入力を横並び（PC）または縦並び（モバイル）
- 検索ボタン: プライマリカラー（#1a73e8）

**図書カード**:
- 横並びのカード型（タイトル・著者・カテゴリ・在庫状況を表示）
- 在庫あり: 「貸出可能 N冊」をグリーンのバッジで表示
- 在庫なし: 「全冊貸出中」をグレーのバッジで表示（最短返却予定日を表示）
- 図書タイトルはリンク（SCR005 へ）
- ADMINのみ: 図書追加ボタン（ページ右上）

**ページネーション**:
- 現在ページをプライマリカラー（#1a73e8）でハイライト
- 前へ/次へボタン

### 2.4 空状態
- 検索結果0件: 「該当する図書が見つかりませんでした」と検索条件クリアボタンを表示
- 初期表示（検索前）: 全件を表示

### 2.5 ローディング状態
- スケルトンカード（6件分）を表示

### 2.6 エラー状態
- API エラー: エラーメッセージとリロードボタン

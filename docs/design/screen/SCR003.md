## 2. デザイン仕様（パターンB）

### 2.1 ナビゲーション構造
- SCR002 と同じドロワーメニュー構造を使用
- 現在のアクティブメニュー: 「ダッシュボード」をハイライト表示

### 2.2 カラー仕様

| 要素 | カラーコード |
|------|------------|
| 背景色 | #f8f9fa |
| カード背景 | #ffffff |
| プライマリカラー | #1a73e8 |
| 警告色（延滞） | #f29900 |
| エラー色（延滞超過） | #d93025 |
| 成功色（返却済） | #1e8e3e |
| テキスト | #202124 |

### 2.3 コンポーネントスタイル

**サマリカード（貸出状況）**:
- 貸出件数 / 最大5冊の表示
- プログレスバー（貸出割合）: primary色
- 延滞中の場合: 警告アイコンと赤色テキストで表示

**貸出中図書カード**:
- 図書タイトル、著者名、貸出日、返却期限を表示
- 返却期限が本日または過去: 赤色でハイライト（延滞表示）
- 返却期限まで3日以内: 警告色（オレンジ）でハイライト
- 返却ボタン: アクセントカラー（#00897b）

**延滞警告バナー**:
- 画面上部に赤色のアラートバナー
- 「延滞中の図書があります。返却してください。」

### 2.4 空状態
- 貸出中図書が0件の場合: 「現在貸出中の図書はありません」と「図書を探す」リンクボタンを表示

### 2.5 ローディング状態
- スケルトンカードを表示

### 2.6 エラー状態
- API エラー時: エラーメッセージとリロードボタンを表示

| ユーザ状態 | B12 サマリカード | B13 延滞警告バナー | B14 貸出中図書カード | B15 返却ボタン | B16 図書タイトルリンク |

| 貸出なし | 表示（活性） | 非表示 | 非表示（空状態表示） | 非表示 | 非表示 |
| 貸出あり・延滞なし | 表示（活性） | 非表示 | 表示（活性） | 表示（活性） | 表示（活性） |
| 貸出あり・延滞あり | 表示（活性） | 表示（活性） | 表示（活性） | 表示（活性） | 表示（活性） |
| 上限到達（5冊貸出中） | 表示（活性）※上限表示 | 非表示（延滞なしの場合） | 表示（活性） | 表示（活性） | 表示（活性） |

## 5. アクション定義

| アクションID | 説明 | トリガー | APIエンドポイント | 動作 |

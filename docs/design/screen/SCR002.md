## 2. デザイン仕様（パターンB）

### 2.1 ナビゲーション構造
- **ドロワーメニュー（パターンB）**: ハンバーガーアイコンで開閉するサイドドロワー
- PC（≥1024px）: ピン留めボタンで常時表示モードに切り替え可能。ピン留め状態は localStorage に保存
- タブレット・モバイル: オーバーレイ形式（ドロワー展開時に背景をオーバーレイ）
- ドロワー内ナビゲーションリンク:
  1. アクティビティフィード（現在画面）
  2. ダッシュボード
  3. 図書を探す
  4. 貸出履歴
  5. 予約一覧
  6. 図書管理（ADMINのみ表示）
  7. ユーザ管理（ADMINのみ表示）
- ヘッダー右側: アバターアイコン（プロフィール画面へのリンク）、ログアウトボタン

### 2.3 コンポーネントスタイル

**タイムラインカード（アクティビティアイテム）**:
- 左側にアクティビティ種別アイコン（貸出: 📚緑、返却: ↩グレー、予約: 🔖青）
- カード: background #ffffff、border-radius: 8px、box-shadow、padding: 16px
- 図書タイトルはリンク（クリックで SCR005 へ遷移）
- 日時は相対表示（例: 「3時間前」「昨日」）またはフォーマット日時

**ドロワー**:
- 幅: 280px
- border-right: 1px solid #e0e0e0
- ナビゲーションアイテム: padding: 12px 16px、hover時: background #f5f5f5

### 2.4 空状態
- アクティビティが0件の場合: 中央に「まだアクティビティがありません」と説明テキストを表示
- アイコン（📚）と「図書を探すへ」のリンクボタンを表示

### 2.5 ローディング状態
- ページ読込中: スケルトンカード（3〜5件分）を表示

### 2.6 エラー状態
- API エラー時: 「アクティビティの読み込みに失敗しました。再読み込みしてください。」とリロードボタンを表示

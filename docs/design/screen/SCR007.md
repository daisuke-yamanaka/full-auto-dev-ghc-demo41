## 2. デザイン仕様（パターンB）

### 2.1 ナビゲーション構造
- SCR002 と同じドロワーメニュー構造
- アクティブメニュー: 「貸出履歴」をハイライト

### 2.2 カラー仕様

| 要素 | カラーコード |
|------|------------|
| 背景色 | #f8f9fa |
| カード背景 | #ffffff |
| プライマリカラー | #1a73e8 |
| ステータス: ACTIVE（貸出中） | #1a73e8 |
| ステータス: OVERDUE（延滞中） | #d93025 |
| ステータス: RETURNED（返却済） | #1e8e3e |

### 2.3 コンポーネントスタイル

**貸出履歴カード / テーブル行**:
- PC: テーブル形式（図書名・著者・貸出日・返却期限・返却日・ステータス・操作）
- モバイル: カード形式で各貸出情報を表示
- ステータスチップ: 角丸バッジで色分け（ACTIVE=青、OVERDUE=赤、RETURNED=緑）
- 図書タイトルはリンク（SCR005 へ）
- 未返却（ACTIVE/OVERDUE）の図書には「返却する」ボタンを表示

### 2.4 空状態
- 履歴が0件: 「貸出履歴がありません」と「図書を探す」リンクボタンを表示

### 2.5 ローディング状態
- スケルトンテーブル/カードを表示

### 2.6 エラー状態
- API エラー: エラーメッセージとリロードボタンを表示

## 4. ボタン表示条件

| ユーザ状態 | B12 履歴一覧 | B13 ステータスチップ | B14 返却ボタン | B15 図書タイトルリンク | B16 ページネーション |

| 履歴あり（全件返却済） | 表示（活性） | 表示（活性）RETURNED | 非表示 | 表示（活性） | 表示（活性） |
| 履歴あり・未返却あり（通常） | 表示（活性） | 表示（活性）ACTIVE | 表示（活性） | 表示（活性） | 表示（活性） |
| 履歴あり・延滞あり | 表示（活性） | 表示（活性）OVERDUE | 表示（活性） | 表示（活性） | 表示（活性） |
| 履歴なし | 非表示（空状態表示） | 非表示 | 非表示 | 非表示 | 非表示 |

共通ボタン（B01〜B11）は全ユーザ状態で SCR002 と同様のルール。

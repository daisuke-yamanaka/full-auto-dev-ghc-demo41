## 1. 用語集

| 用語 | 定義 |
|------|------|
| ユーザ | システムを利用するアカウントの総称（通常ユーザ・管理者ユーザを含む） |
| 通常ユーザ | 図書の検索・貸出・返却・予約・履歴確認を行うアカウント |
| 管理者ユーザ | 通常ユーザの権限に加え、図書管理・ユーザ管理を行うアカウント |
| 図書 | 図書館に登録されたタイトル単位の書籍情報（複数冊を持てる） |
| 蔵書 | 図書の物理的な1冊を表す単位 |
| 貸出 | ユーザが蔵書を借りる行為・その状態 |
| 返却 | ユーザが貸出中の蔵書を返す行為 |
| 予約 | 貸出中の図書に対して、返却後の優先貸出を申し込む行為 |
| 貸出期限 | 貸出日から7日後（翌週の同曜日）の返却期日 |
| 延滞 | 貸出期限を超えても返却されていない状態 |
| ダッシュボード | ログイン後、現在の貸出状況（借りている図書一覧）を表示する画面 |
| アクティビティフィード | ログイン後の遷移先画面。最新の貸出・返却・予約をタイムライン表示する画面 |
| ページネーション | 一覧データを複数ページに分割して表示する機能（1ページ最大20件） |
| 楽観的排他制御 | バージョン番号により同時更新の衝突を検知する排他制御方式 |
| フォントサイズ切り替え | 標準・大・特大の3段階でUI全体の文字サイズを変更する機能 |

## 2. システム概要

### 2.1 目的

本システムは、図書館の蔵書を管理し、ユーザが図書の検索・貸出・返却・予約を行えるWebシステムです。管理者は図書およびユーザを管理できます。

### 2.2 スコープ

- 図書の検索・詳細表示・貸出・返却・予約
- ユーザのプロフィール管理・パスワード変更・貸出履歴確認
- 管理者による図書登録・編集・削除・ユーザ管理
- PC・スマートフォン対応のレスポンシブWebUI

### 2.3 対象ユーザ

- 図書を利用する一般ユーザ（通常ユーザ）
- 図書・ユーザを管理する図書館スタッフ（管理者ユーザ）

## 5. 機能要件

### FR-001: ログイン機能

| 項目 | 内容 |
|------|------|
| 説明 | ユーザはユーザIDまたはメールアドレスとパスワードを入力してシステムにログインできる |
| 優先度 | 必須 |
| 対応ヒアリング | H-001, H-006 |

**受け入れ条件**

| 種別 | 条件 |
|------|------|
| 正常系 | 有効なユーザIDまたはメールアドレスと正しいパスワードを入力するとログインに成功し、アクティビティフィード画面へ遷移すること |
| 正常系 | ユーザIDとメールアドレスのどちらでもログインできること |
| 異常系 | 存在しないユーザIDを入力した場合、「ユーザIDまたはパスワードが正しくありません」のエラーメッセージが表示されること |
| 異常系 | 正しいユーザIDと誤ったパスワードを入力した場合、「ユーザIDまたはパスワードが正しくありません」のエラーメッセージが表示されること |
| 異常系 | ユーザIDまたはパスワードが未入力の場合、送信ボタンを押せない（または「必須項目を入力してください」と表示される）こと |
| 異常系 | 別端末ですでにログイン中のアカウントで再ログインした場合、既存セッションが無効化され、新しいセッションでのみ利用可能となること |

### FR-002: ログアウト機能

| 項目 | 内容 |
|------|------|
| 説明 | ログイン中のユーザがシステムからログアウトできる |
| 優先度 | 必須 |
| 対応ヒアリング | H-001 |

**受け入れ条件**

| 種別 | 条件 |
|------|------|
| 正常系 | ログアウト操作を行うとセッションが破棄され、ログイン画面へ遷移すること |
| 正常系 | ログアウト後にブラウザの戻るボタンを押しても認証が必要なページへアクセスできないこと |

### FR-003: セッション管理

| 項目 | 内容 |
|------|------|
| 説明 | セッションタイムアウトおよび多重ログイン防止を行う |
| 優先度 | 必須 |
| 対応ヒアリング | H-001 |

**受け入れ条件**

| 種別 | 条件 |
|------|------|
| 正常系 | 最終操作から30分経過後に自動的にログアウトされ、ログイン画面へ遷移すること |
| 正常系 | セッションタイムアウト後にページ操作を行うと「セッションがタイムアウトしました。再度ログインしてください。」のメッセージが表示されること |
| 正常系 | 同一アカウントで別端末にログインした場合、既存のセッションが無効化されること |

---

### FR-004: プロフィール編集機能

| 項目 | 内容 |
|------|------|
| 説明 | 通常ユーザおよび管理者ユーザは自分の表示名（名前）を変更できる |
| 優先度 | 必須 |
| 対応ヒアリング | H-010 |

**受け入れ条件**

| 種別 | 条件 |
|------|------|
| 正常系 | プロフィール画面で名前を変更して保存すると、変更が即座に画面に反映されること |
| 正常系 | 保存成功時に「プロフィールを更新しました」の通知（スナックバー）が表示されること |
| 異常系 | 名前が未入力の場合、「名前を入力してください」のエラーメッセージが表示されること |
| 異常系 | 楽観的排他制御により、同一ユーザが別端末で更新した後に古いデータで保存しようとした場合、「他の端末から変更が行われました。再読み込みしてください。」のエラーメッセージが表示されること |

### FR-005: パスワード変更機能

| 項目 | 内容 |
|------|------|
| 説明 | ユーザは自分のパスワードを変更できる。現在のパスワードと新しいパスワード（2回）を入力する |
| 優先度 | 必須 |
| 対応ヒアリング | H-011 |

**受け入れ条件**

| 種別 | 条件 |
|------|------|
| 正常系 | 現在のパスワード・新パスワード・新パスワード（確認）を正しく入力して変更すると、「パスワードを変更しました」の通知が表示されること |
| 正常系 | 新パスワードが推奨強度（8文字以上、英数字混在）を満たしている場合に強度インジケーターが「強」と表示されること（入力は強制されない） |
| 正常系 | 新パスワードが推奨強度を満たさない場合でも保存可能であること |
| 異常系 | 現在のパスワードが正しくない場合、「現在のパスワードが正しくありません」のエラーメッセージが表示されること |
| 異常系 | 新パスワードと確認用パスワードが一致しない場合、「新パスワードが一致しません」のエラーメッセージが表示されること |
| 異常系 | 必須項目（現在のパスワード・新パスワード・確認）が未入力の場合、「必須項目を入力してください」のエラーメッセージが表示されること |

### FR-006: フォントサイズ切り替え機能

| 項目 | 内容 |
|------|------|
| 説明 | ユーザはUI全体のフォントサイズを標準・大・特大の3段階で切り替えられる。設定はプロフィール画面から行い、ローカルストレージまたはユーザ設定として保存される |
| 優先度 | 必須 |
| 対応ヒアリング | H-004, H-010 |

**受け入れ条件**

| 種別 | 条件 |
|------|------|
| 正常系 | フォントサイズを「標準」「大」「特大」のいずれかに設定すると、全画面で即座にフォントサイズが切り替わること |
| 正常系 | 設定したフォントサイズが次回ログイン後も維持されること |
| 正常系 | ページを遷移しても設定したフォントサイズが維持されること |

### FR-007: 図書検索・一覧表示機能

| 項目 | 内容 |
|------|------|
| 説明 | ユーザはタイトル・著者名・カテゴリ・ISBNで図書を絞り込み検索できる。検索条件は複数組み合わせ可能。結果はページネーションで表示する |
| 優先度 | 必須 |
| 対応ヒアリング | H-017, H-023 |

**受け入れ条件**

| 種別 | 条件 |
|------|------|
| 正常系 | タイトル・著者名のいずれか、または組み合わせで部分一致検索できること |
| 正常系 | カテゴリはドロップダウンから選択して絞り込めること |
| 正常系 | ISBNは完全一致または部分一致で検索できること |
| 正常系 | 検索結果が0件の場合、「該当する図書が見つかりませんでした」のメッセージが表示されること |
| 正常系 | 検索結果は1ページ最大20件のページネーションで表示されること |
| 正常系 | 各図書カードに貸出状況（貸出可能冊数）が表示されること |
| 正常系 | 貸出中の場合は最短の返却予定日が表示されること |

| 項目 | 内容 |
|------|------|

### FR-009: 図書登録機能（管理者）

| 項目 | 内容 |
|------|------|
| 説明 | 管理者ユーザは新規図書を登録できる。登録項目はタイトル・著者名・ISBN・出版社・出版年・カテゴリ・所蔵冊数 |
| 優先度 | 必須 |
| 対応ヒアリング | H-007, H-018 |

**受け入れ条件**

| 種別 | 条件 |
|------|------|
| 正常系 | 必須項目（タイトル・著者名・ISBN・出版社・出版年・カテゴリ・所蔵冊数）を全て入力して登録すると、図書一覧に追加されること |
| 正常系 | 登録成功時に「図書を登録しました」の通知（スナックバー）が表示されること |
| 異常系 | 必須項目が未入力の場合、該当フィールドに「必須項目です」のエラーが表示されること |
| 異常系 | ISBNが既に登録されているものと重複している場合、「このISBNは既に登録されています」のエラーメッセージが表示されること |
| 異常系 | 所蔵冊数に0以下の値を入力した場合、「所蔵冊数は1以上を入力してください」のエラーメッセージが表示されること |
| 権限 | 通常ユーザがアクセスした場合、403エラーページが表示されること |

### FR-012: 図書貸出機能

| 項目 | 内容 |
|------|------|
| 説明 | 通常ユーザおよび管理者ユーザは図書を貸し出すことができる。貸出上限は1ユーザにつき5冊まで。貸出期限は貸出日の7日後（翌週の同曜日） |
| 優先度 | 必須 |
| 対応ヒアリング | H-009, H-014, H-015 |

**受け入れ条件**

| 種別 | 条件 |
|------|------|
| 正常系 | 貸出可能な蔵書がある図書を選択して貸出操作を行うと、貸出が記録され、貸出期限（貸出日の7日後）が設定されること |
| 正常系 | 貸出成功後、ダッシュボードに貸出した図書が表示されること |
| 正常系 | 貸出期限は「貸出日の7日後」として設定されること（例：月曜日に貸し出した場合、翌週月曜日が返却期限） |
| 異常系 | 現在5冊借りているユーザが貸出を試みた場合、「貸出上限（5冊）に達しています」のエラーメッセージが表示されること |
| 異常系 | 延滞中のユーザが新規貸出を試みた場合、「延滞中の図書を返却するまで貸出できません」のエラーメッセージが表示されること |
| 異常系 | 全冊貸出中の図書を貸し出そうとした場合、「現在貸出可能な蔵書がありません」のエラーメッセージが表示されること |

### FR-014: 貸出上限制御

| 項目 | 内容 |

## 6. 非機能要件

### 6.1 パフォーマンス要件

| 項目 | 要件 |
|------|------|
| レスポンスタイム | 通常操作時（同時接続数50人の環境下）でAPIレスポンスタイムが2秒以内であること |
| 同時接続数 | 最低50人の同時接続に対応できること |
| ページネーション | 一覧画面は1ページあたり最大20件を表示すること |

### 6.2 セキュリティ要件

| 項目 | 要件 |
|------|------|
| セッションタイムアウト | 最終操作から30分後に自動ログアウトすること |
| 多重ログイン防止 | 同一アカウントの同時セッション数を1に制限し、後からのログインが優先されること |
| ログイン試行回数制限 | 現時点では制限なし（将来拡張として設計に考慮すること） |
| 開発用ツール | H2コンソール等の開発用ツールは開発環境のみ有効とし、本番環境では無効にすること |
| 機密情報管理 | 本番環境のDB接続パスワード等の機密情報は環境変数で管理し、デフォルト値（空文字含む）を設定しないこと。環境変数未設定時はアプリ起動失敗とすること |
| CSRF対策 | ログインページを含む全ページにCSRF対策を適用すること |

### 6.3 可用性要件

| 項目 | 要件 |
|------|------|
| 稼働率目標 | 99%以上（月次） |
| RTO（目標復旧時間） | 障害発生から4時間以内に復旧すること |

### 6.4 保守性要件

| 項目 | 要件 |
|------|------|
| コードカバレッジ | 単体テストのコードカバレッジ90%以上を維持すること |
| マジックナンバー排除 | 貸出上限冊数（5冊）・貸出期限日数（7日）等のビジネスルール数値は定数として管理し、コード中に直接記述しないこと |
| ドキュメント | 要件定義書・設計書・テスト仕様書等はmdファイルとして残すこと |

### 6.5 拡張性要件

| 項目 | 要件 |
|------|------|
| 水平スケーリング | ステートレスなセッション管理（JWT等）により将来的な水平スケーリングに対応できること |
| 環境切り替え | 開発環境と本番環境の切り替えは環境変数で行うこと |

### 6.6 ユーザビリティ要件

| 項目 | 要件 |
|------|------|
| フォントサイズ | 標準・大・特大の3段階でフォントサイズを切り替えできること |
| アクセシビリティ | 操作対象のボタン・リンクはタッチターゲットが最小44×44pxであること |
| エラーメッセージ | エラー発生時は具体的かつ分かりやすいメッセージをユーザに提示すること |

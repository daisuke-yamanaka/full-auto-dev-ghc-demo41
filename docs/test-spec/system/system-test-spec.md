# システムテスト仕様書

## 概要

図書管理システムの E2E（エンドツーエンド）テスト仕様書です。
Playwright を使用して、ブラウザ上での実際のユーザ操作を自動化してテストします。

## テスト環境

| 項目 | 内容 |
|------|------|
| テストフレームワーク | Playwright |
| ブラウザ | Chromium |
| フロントエンド URL | http://localhost:5173 |
| バックエンド URL | http://localhost:8080 |
| プロファイル | dev（DataInitializer により初期データ投入） |

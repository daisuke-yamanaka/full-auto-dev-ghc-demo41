概要・あらすじ

「吾輩は猫である。名前はまだ無い。」という書き出しで有名な夏目漱石の長編小説。猫の視点から、明治時代の中産階級の知識人社会を鋭く諷刺した作品。珍野苦沙弥の家に住み着いた猫が、主人や周囲の人間たちの言動を観察し、ユーモラスかつ批判的に語る構成となっている。1905年から1906年にかけて雑誌「ホトトギス」に連載された漱石の処女長編作品。

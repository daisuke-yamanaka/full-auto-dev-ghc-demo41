# 図書管理システム モックアップ

## 概要

本ディレクトリには、図書管理システムのUIモックアップを3パターン用意しています。
各パターンはナビゲーション構造・画面遷移・ダッシュボードの有無が異なる構造的バリエーションです。

**採用パターン：パターンB（ドロワーメニュー型 ＋ Material Designインスパイア）**

---

## パターン一覧

### パターンA：ダッシュボード集約型 ＋ レスポンシブサイドバーナビ

📁 [`pattern-a/`](./pattern-a/)

|------|------|
| コンセプト | 業務系SaaSアプリに近い、情報俯瞰型のプロフェッショナルUI |

## 共通仕様

- **技術**: 静的HTML+CSS（外部ファイル不要、各HTMLで完結）
- **JavaScript**: ドロワー開閉・モーダル・スナックバー等のUI補助のみ
- **レスポンシブ**: PC（≥1024px）・タブレット・スマホ（≥360px）対応
- **アクセシビリティ**: WCAG 2.1 AA準拠（コントラスト比4.5:1以上）
- **フォントサイズ**: 標準・大・特大の3段階切り替え対応

---

## 採用理由（パターンB選定）

パターンBを採用する理由：
1. Google Workspace・Android標準アプリに近い操作感で、幅広い年齢層に馴染みやすい
2. ドロワーメニューはモバイルとPCの両方に最適化されたナビゲーション
3. Material Design準拠のカードUIが情報を見やすく整理
4. アクティビティフィードを起点とすることで、ユーザが利用状況を即座に把握できる
5. ティール＋Googleブルーの配色が明るく親しみやすい（子供から高齢者まで対応）
